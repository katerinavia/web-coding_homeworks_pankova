# МХЛ — React-приложение для покупки билетов

Проект переписан на React. Интерфейс формируется React-компонентами, состояние хранится в хуках, прямые манипуляции DOM (`innerHTML`, `querySelector`, `createElement` и обработчики через `addEventListener`) не используются.

## Запуск

1. Установите Node.js (версия 18 или новее).
2. Распакуйте архив и откройте папку проекта в VS Code.
3. В терминале выполните:

```bash
npm install
npm run dev
```

4. Откройте адрес, который покажет Vite (обычно `http://localhost:5173`).

Для production-сборки: `npm run build`. Проверка готовой сборки: `npm run preview`.

## Реализованные возможности

- Главная страница со списком матчей и фильтром по городу.
- Каталог команд и страницы отдельных команд.
- Добавление и удаление команд из избранного; данные сохраняются в `localStorage`.
- Выбор места на схеме зала, расчёт цены и переход к оформлению билета.
- Демонстрационная форма оплаты с форматированием номера карты и проверкой обязательных полей. Реальная оплата не выполняется, данные карты не отправляются и не сохраняются.
- Страница ближайших домашних матчей.
- Модальное окно поддержки.
- Notification API: кнопка «Уведомить» на карточке матча, запрос разрешения браузера и системное уведомление с командами, датой, временем и ареной. Обработаны неподдерживаемый API, небезопасный контекст, отказ/отсутствие разрешения и ошибки создания уведомления.

## Как выполнены критерии React

1. **Полностью React:** приложение монтируется через `createRoot`; интерфейс и модальные окна создаются JSX. Нет ручного изменения DOM и делегирования DOM-событий.
2. **Компонентная архитектура:** повторно используемые элементы находятся в отдельных файлах каталога `src/components`.
3. **Модульные стили:** `App.module.css` импортируется как CSS Module и применяется через `styles.app`. Адаптивные стили интерфейса подключены отдельно.
4. **Хуки:** `useState` хранит состояние города, избранного, текущего матча, места, форм и модальных окон; `useEffect` подписывается на событие навигации браузера и снимает подписку при размонтировании; `useMemo` оптимизирует фильтрацию матчей.

## Примечания

- Notification API работает в защищённом контексте: HTTPS или localhost. Браузер должен поддерживать уведомления, а пользователь — разрешить их.
- Уведомление показывается по нажатию кнопки. Автоматическая отправка напоминаний при закрытом сайте не реализована.
- Маршруты `/`, `/teams`, `/team?team=dynamo-m`, `/favorites`, `/booking`, `/checkout`, `/arena` обрабатываются внутри React-приложения. Vite обеспечивает fallback на `index.html` в режиме разработки и предпросмотра.
